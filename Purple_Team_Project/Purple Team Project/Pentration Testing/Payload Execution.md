# Metasploit Payload Execution Test

## 1. Objective

The objective of this test was to simulate payload execution in the lab environment and examine the activity generated on the Windows endpoint.

## 2. Lab Environment

- **Attacker Machine:** Kali Linux
    
- **Target Machine:** Windows Endpoint
    
- **Target IP:** `192.168.255.148`
    
- **Tool:** Metasploit Framework
    
- **Monitoring Platform:** Wazuh
    

## 3. Test Procedure

A payload named `payload(2).exe` was executed on the Windows endpoint as part of the lab's attack simulation.

The test focused on examining the endpoint's behavior and reviewing the available Windows events in Wazuh following execution.

## 4. Results

The payload test was performed as part of the lab's attack simulation. Following execution, the Windows endpoint was monitored through Wazuh to review relevant system events and identify activity associated with the test.

## 5. Analysis

The collected Windows events were reviewed in Wazuh to examine activity around the test time. An event associated with `payload(2).exe` was identified in the Windows Application log.

The event was generated by Windows Error Reporting and included the report name `RADAR_PRE_LEAK_64`. Wazuh collected this event under Rule ID `60608`, with an alert level of 4.

This finding provided a starting point for investigating the endpoint's behavior following the test.

## 6. Conclusion

This test provided an opportunity to examine Windows endpoint events following payload execution and review the collected data through Wazuh. The investigation identified a Windows Error Reporting event referencing the payload filename, demonstrating that related application event data was available for analysis.
